# RAYAN-8 CPU Block Diagram

## 1. Overview

The RAYAN-8 processor consists of a Program Counter, Instruction Memory, Instruction Register, Control Unit, Register File, Arithmetic Logic Unit, Flag Register and Data Memory.

## 2. Component Functions

- Program Counter: Maintains the instruction address.
- Instruction Memory: Stores the program instructions.
- Instruction Register: Holds the current instruction.
- Control Unit: Decodes instructions and generates control signals.
- Register File: Contains four 8-bit general-purpose registers.
- ALU: Performs arithmetic and logical operations.
- Flag Register: Stores Zero and Carry status flags.
- Data Memory: Stores program data.

## 3. Data Flow

The PC selects an instruction from Instruction Memory. The instruction is transferred to the IR and decoded by the Control Unit.

The Register File supplies operands to the ALU. The ALU performs the requested operation and returns results to the Register File. For memory instructions, data is transferred between the Register File and Data Memory.

The Flag Register stores the status information generated by applicable ALU operations.
